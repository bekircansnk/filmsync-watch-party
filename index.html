Şimdi inen ZIP dosyasını klasöre çıkartın, chrome://extensions adresini açıp Geliştirici Modu'nu açın ve Paketlenmemiş öğe yükle ile klasörü seçin.

🚀 Google Chrome & Edge Hızlı Kurulum (30 Saniye) v1.3.0 Hazır Paket

  1. Yukarıdaki 📥 Eklentiyi İndir (.ZIP) butonuna tıklayın ve inen film-partisi-extension.zip dosyasını masaüstüne klasöre çıkartın.
  2. Tarayıcınızda chrome://extensions sayfasını açın.
  3. Sağ üst köşedeki Geliştirici modu (Developer mode) anahtarını aktif edin.
  4. Sol üstteki Paketlenmemiş öğe yükle (Load unpacked) butonuna basıp çıkarttığınız klasörün içindeki extension klasörünü seçin.
  5. Kurulum tamamlandı! Eklenti yüklendiği anda bu sayfa otomatik olarak yeşile dönecek ve partiye bağlanacaktır.

Yöntem 2 — GitHub Pages (bekircansnk.github.io/filmsync-watch-party) Aktifleştirme:
1. GitHub deponuzda (bekircansnk/filmsync-watch-party) üst menüden Settings (Ayarlar) sekmesine girin.
2. Eğer depo Özel (Private) ise en alttaki Danger Zone → Change repository visibility → Make public ile herkese açık yapın.
3. Sol menüden Pages sekmesine tıklayın; Build and deployment → Source kısmını GitHub Actions (veya Deploy from a branch → main → /docs) olarak seçip kaydedin.
4. Deponun ana sayfasında sağ üstteki Hakkında (About) ⚙️ çark simgesine tıklayıp "Use your GitHub Pages website" kutusunu işaretleyin; böylece GitHub sayfasında doğrudan tıklanabilir web sitesi linkiniz görünür!
