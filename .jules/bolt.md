## 2024-05-18 - Throttling Global Events for Video Playback Performance
**Learning:** Attaching continuous global event listeners (like `mousemove` and `keydown` for idle detection) over heavy video players without throttling can cause significant DOM recalculation storms and main thread contention, leading to dropped frames during playback. Furthermore, standard blocking listeners can intercept critical interactions.
**Action:** When handling frequent global events like `mousemove` and `scroll` for UI management, always apply a timestamp-based throttle (e.g., executing the callback at most every 250ms). Additionally, append the `{ passive: true }` option to document-level listeners to inform the browser that `preventDefault()` will not be called, unblocking native interactions.
