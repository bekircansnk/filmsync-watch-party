## 2024-05-24 - Firebase Query Listener Teardown
**Learning:** Calling `.off()` on a base Firebase reference (e.g., `db.ref('rooms/123/messages').off()`) removes all listeners at that location, but if the original listener was attached to a specific query (e.g., `db.ref(...).limitToLast(50).on(...)`), calling `.off()` on the base reference without the query chain fails to explicitly detach the query listeners in some SDK versions, leading to memory leaks and zombie listeners in long-running video tabs.
**Action:** When managing Firebase Realtime Database listeners, always explicitly call `.off()` on the exact same query chain (e.g., `.limitToLast(50).off()`) that was used for the `.on()` registration in the teardown functions like `cleanupFirebase()` to ensure complete listener removal.
