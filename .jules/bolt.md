## 2024-05-14 - Optimize global mousemove and keydown event listeners
**Learning:** Frequent continuous global events like `mousemove` and `keydown` can fire up to 60 times per second, leading to DOM recalculation storms and main thread contention, especially over video players. Additionally, listeners attached to global objects without the `{ passive: true }` option can block default main thread operations like scrolling or interactions because the browser has to wait to see if `preventDefault()` will be called.
**Action:** Throttle or debounce such event listeners (e.g., using a timestamp-based check like `if (now - lastMoveTime < 200) return;`) and always append the `{ passive: true }` option when attaching them to global objects like `document` unless `preventDefault()` is strictly necessary.
