## 2026-08-04 - [Unthrottled MouseMove Events on Video Players]
**Learning:** Frequent continuous global events like `mousemove` can cause main thread contention and DOM recalculation storms, especially over video players rendering at high frame rates. This contention can lead to stuttering and dropped frames in the video playback.
**Action:** Always throttle or debounce frequent global events (like `mousemove`, `scroll`, or `resize`). For UI visibility checks, throttling to once every 200ms is usually sufficient without feeling laggy. Furthermore, always append `{ passive: true }` to the event listener options when attaching generic UI event listeners to global objects like `document`. This ensures the browser knows the event handler won't call `preventDefault()`, preventing it from blocking default main thread operations.
