## 2024-11-25 - Prevent MutationObserver Duplication and Main Thread Blocking
**Learning:** Attaching a generic, un-throttled `MutationObserver` to `document.body` on highly dynamic SPAs (like Netflix) triggers an immense number of callbacks. If this observer lacks initialization checks, re-invoking the setup function can cause duplicate observers. Together, this rapidly blocks the main thread, degrading UI performance (stuttering).
**Action:** When using `MutationObserver` on `document.body` for dynamic sites, always wrap the callback in a debounce timer (e.g., 200ms) and use a boolean flag (`isInitialized`) to prevent attaching multiple identical observers on subsequent setup calls. Also, fixed a pre-existing syntax error in regex flags (`replace(/\\/$/, '')` -> `replace(/\/$/, '')`).
