## 2026-08-10 - Throttling Global Event Listeners & Passive Events
**Learning:** Frequent continuous global events (like `mousemove`, `scroll`, or `resize`) must be throttled or debounced (e.g., using a timestamp-based check) to prevent DOM recalculation storms and main thread contention, especially over video players. Additionally, attaching generic UI event listeners to global objects like `document` should include the `{ passive: true }` option to ensure the browser knows the event handler won't block default main thread operations like scrolling or interactions.
**Action:** When adding global UI listeners for events like `mousemove` and `keydown`, throttle the function execution and add `{ passive: true }` to the options to maintain high video playback frame rates and reduce main thread workload.
