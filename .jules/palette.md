## 2024-05-24 - Convert Text Descriptors to Interactive Labels for Form Accessibility
**Learning:** In the FilmSync popup UI, several text elements (like `.switch-text` or `.section-title`) acted visually as input descriptors but were not semantically linked as `<label>` tags. This caused reduced clickable areas and screen reader unfriendliness. Using `<label for="inputId">` along with `.avatar-list` as `role="group"` dramatically improves keyboard navigation and usability. Adding `cursor: pointer` via existing tag selectors avoids inline styling.
**Action:** When evaluating forms or custom toggles, always check if text descriptors are properly linked via `<label>` tags and if groups of interactive elements use `role="group"`. Do not assume descriptive `<span>` or `<div>` elements are accessible by default. Apply `cursor: pointer` CSS to indicate interactability.
