## 2026-07-19 - [HIGH] Fix path traversal vulnerability in background service worker
 **Vulnerability:** Unauthenticated clients could trigger `page-unload` messages sending arbitrary `roomId` payload to `extension/background.js`. Since `background.js` blindly appended `roomId` into the Firebase RTDB REST endpoint without validation, this allowed Path Traversal injections leading to unauthorized writes/modifications of any part of the Firebase database.
 **Learning:** In isolated context scripts (like Service Workers acting as proxies for REST APIs without Firebase Auth), untrusted payloads sent via Chrome messaging API must be thoroughly validated and strictly type-checked against regex masks before being concatenated into URLs or database references.
 **Prevention:** Added strict regex validation `/^[A-Z0-9_-]{4,20}$/i` on the incoming `roomId` payload in `background.js` before calling the REST endpoints, rejecting requests that try to traverse directories or contain malformed keys.
