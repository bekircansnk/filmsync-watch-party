## 2026-08-21 - Fix Path Traversal Risk in Firebase REST URLs
**Vulnerability:** The extension dynamically builds Firebase REST endpoint URLs by concatenating unsanitized fields from Chrome message payloads (e.g. `roomId` and `userId`) directly into `fetch()` paths. This creates a Path Traversal vulnerability where an attacker could send maliciously crafted identifiers containing `/` or `.json` to overwrite or access arbitrary Firebase nodes, bypassing intended scope (though protected by Firebase rules, defense in depth is missing).
**Learning:** In browser extensions, message listeners often act as security boundaries, treating incoming messages from content scripts or other tabs as untrusted input. Concatenating these untrusted inputs directly into REST API URLs without prior regex validation is a dangerous pattern.
**Prevention:** Always strictly validate any dynamic variables (like `roomId`, `userId`) meant for URL paths against an explicit allowlist regex (e.g., `/^[a-zA-Z0-9_-]+$/`) before using them in any fetch requests to prevent path injection.
