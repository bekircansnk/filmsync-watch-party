## 2026-09-24 - Improve accessibility of interactive elements
**Learning:** Some custom UI components in this extension (like the profile avatar badge and room ID display) were created using span or div elements, but act as interactive buttons for users to click. Inputs in the popup were also missing appropriate aria-label attributes since they did not have visual label elements. Furthermore, the user configuration area lacked visual feedback when focusing on its inputs.
**Action:** Always ensure that custom interactive span or div elements contain role="button", tabindex="0", aria-label, and have keyboard event listeners for 'Enter' and 'Space' to be fully accessible. Always add aria-label to form inputs missing a visual label. Add a :focus-within styling to custom wrapper containers around inputs to provide visual feedback for keyboard navigation.
