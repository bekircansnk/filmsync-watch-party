## 2026-08-08 - Accessible Icon Buttons & Inputs without visual labels
**Learning:** In this extension's UI (specifically the popup), there are text inputs like `usernameInput` and `joinRoomCodeInput` that rely solely on placeholders without explicit visual `<label>` tags. Screen readers cannot properly identify these without `aria-label`. Similarly, the avatar switcher (`userAvatarDisplay`) uses an emoji inside a `<span>` as an interactive button but lacks `role="button"`, `tabindex="0"`, `aria-label`, and keyboard event handlers (`keydown` for Enter/Space), making it inaccessible for keyboard users and screen readers.
**Action:** For all inputs relying only on placeholders, ensure an `aria-label` is applied. For any non-button element (like a `span` with an emoji) functioning as a button, add `role="button"`, `tabindex="0"`, an appropriate `aria-label`, a `:focus-visible` styling indicator, and a `keydown` listener to handle `Enter` and `Space` key activation.
