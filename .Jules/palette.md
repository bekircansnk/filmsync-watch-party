## 2026-10-22 - ARIA Labels for Icon-Only Elements
**Learning:** Added ARIA labels to the avatar selection buttons and switches in the popup interface to improve accessibility for screen readers. Using titles and aria-labels ensures keyboard and visually impaired users can properly interact with interactive icon-only elements.
**Action:** Always ensure any icon-only button or switch includes an `aria-label` providing context or purpose to avoid usability barriers for screen reader users.
