## 2026-08-03 - Form Labels and Emoji Buttons Accessibility
**Learning:** In the FilmSync watch party popup UI, key interactive elements like the dynamic emoji avatar and description texts associated with switches were not explicitly linked to form controls or properly semantically marked for screen readers/keyboard users. Although they functioned visually, lack of `aria-label`, explicit `<label>` association for checkboxes, and `role="button"` + `keydown` support on non-traditional buttons restricted accessibility.
**Action:** When creating custom toggle switches or using emojis as interactive buttons, I will ensure explicit explicit `for` attribute linkages on `<label>` elements, proper `aria-label` tags for icon-only/input fields lacking visual labels, and apply `tabindex="0"`, `focus-visible` styling, and keyboard event handlers (`Enter`/`Space`) for full a11y compliance in vanilla JS setups without native framework helpers.
