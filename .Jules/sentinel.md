## $(date +%Y-%m-%d) - DOM-based XSS Vulnerability Fix
**Vulnerability:** User-provided inputs (room ID, platform name, users text, room name) originating from URL parameters or Firebase DB were being rendered using raw `.innerHTML` without escaping, exposing the extension to DOM-based Cross-Site Scripting (XSS). Additionally, the pre-existing bug `Invalid regular expression flags` with `replace(/\\/$/, '')` in `content.js` was identified.
**Learning:** Using untrusted variables inside template literals directly assigned to `.innerHTML` allows attackers to inject malicious scripts. Even inputs appearing as safe keys (like `roomId`) can be manipulated if drawn from external uncontrolled sources. Fixing `replace(/\\/$/, '')` to `replace(/\/$/, '')` solves syntax errors while keeping functionality.
**Prevention:** Always treat user-provided data as untrusted. Enforce the usage of a secure HTML escape helper function (e.g., `escapeHTML`) when using `.innerHTML`, or assign text values strictly via `.textContent` to prevent DOM-based XSS. Ensure proper regex syntax when escaping backslashes.
