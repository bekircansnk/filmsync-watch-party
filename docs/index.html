🚀 Hızlı Kurulum (1 Dakika)

  1. Yukarıdaki butondan ZIP dosyasını indirin ve bilgisayarınızda klasöre çıkartın.
  2. Chrome veya Edge tarayıcınızda chrome://extensions adresini açın.
  3. Sağ üst köşedeki Geliştirici Modu anahtarını aktif edin.
  4. Sol üstteki Paketlenmemiş öge yükle butonuna basıp çıkarttığınız klasördeki extension klasörünü seçin.
  5. Kurulum tamamlandı! Bu sayfayı yenilediğinizde partiye anında yönlendirileceksiniz.
